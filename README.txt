Carnival Splendor Guide (unofficial, personal use)
1. Upload ALL files and the maps folder to the top level of a GitHub repository (not the zip itself).
2. Settings > Pages > Deploy from a branch > main / (root).
3. Open https://USERNAME.github.io/REPO/ in Safari on the iPhone, Share > Add to Home Screen, open once online.
To update: re-upload changed files and change V='splendor-v1' in sw.js to a new number.
